# better-style upstream

Derived from [minuque/pi-cc-extensions](https://github.com/minuque/pi-cc-extensions) at commit `5d7a2666f51da9f450bd019af10200c88cc1df98` under the MIT License.

Included: compact tool rendering, tool grouping, rich edit/write diff, compact thinking, optional compact transcript mode, Markdown enhancements, working token/time status, agent-run summaries, and the settings panel.

Intentionally excluded: `/context`, session/subagent references, command aliases, the custom startup header, docked-bash patching, bundled themes, and all fullscreen mouse click/hover/scroll behavior. Expansion uses Pi's native keyboard binding.

The rich diff subtree retains its separate attribution to `MasuRii/pi-tool-display`.
