# better-style

A keyboard-first Pi 0.84 TUI presentation extension derived from `pi-cc-extensions`.

- Configure with `/better-style` or `/better-style [on|compact|off|status]`.
- Persistent settings: `~/.pi/agent/better-style.json`.
- Expand tools and thinking with Pi's native `app.tools.expand` keybinding.
- No mouse input interception and no `/context` command are registered by this extension.

See [UPSTREAM.md](./UPSTREAM.md) for scope and attribution.
