模块分层（按职责重新归类）：

| 层 | 模块 | 职责 |
| --- | --- | --- |
| 终端 | DRTC-SDK | 采集、渲染、信令与传输控制；覆盖 Android / iOS / Linux / Web / 鸿蒙，分 Kit SDK + Core SDK 两部分 |

调用链要点：

- **接入前提**：先拿到 app_id / app_key，租户绑定产品、场景与计费，并在管理控制台完成配置。
- **信令主干**：创建 Janus Session → attach（发布者 handle）→ 加入房间 → SDP/ICE 建链 → RTP 传输 → 离开房间 → 销毁 Session。
- **订阅路径**：发布者 RTP 进 SFU，SFU 广播 publisher 事件，订阅者 attach、加入房间、交换 SDP 后收到转发的 RTP。
- **两种模式**：videoroom 以 SDP offer/answer 完成发布与订阅；audiobridge 走 configure + SDP offer，多一步 ICE candidate → webrtcup，退出由 leave / destroy 两条消息收尾。
