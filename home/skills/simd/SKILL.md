# SIMD 优化

1. 先确认热点、数据规模、目标 CPU/ISA、编译器和标量正确性基线。优先检查现成库与编译器自动向量化，不因看见循环就写 intrinsics。
2. 从[模式参考](references/patterns.md)读取匹配当前数据依赖的片段；示例常数、速度与平台结论必须按目标验证。
3. 保持边界、尾部、对齐、别名、符号、溢出和错误语义。无合法可访问 padding 时不做越界向量加载；只在支持的目标调用相应指令。
4. 比较代表性小/大输入和缓存条件；把探测、分派、转换及尾部处理成本计入收益。查看生成代码，测真实调用路径，而不是只比较指令数。

需要多平台支持时保留正确的标量路径及能力检测；固定单平台契约不额外引入通用分派框架。分析请求不改代码。

交付已测收益或待验证假设、正确性证据、目标环境与复现命令。不要把参考案例当成当前机器结果。
